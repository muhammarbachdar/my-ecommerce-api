# E-commerce API

## Tech Stack
- FastAPI (Backend)
- React + Vite (Frontend)
- PostgreSQL (Database)
- Redis (Cache & Queue)
- Celery (Background Task)
- Docker (Container)
- GitHub Actions (CI/CD)
